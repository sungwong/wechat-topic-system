# 选题库使用说明

## 三个文件夹的区别

| 文件夹 | 放什么 | 作用 |
|--------|--------|------|
| 流量选题/ | 带推荐流、能涨粉的题 | 扩大曝光，让新读者找到你 |
| 人设选题/ | 建立信任、展示专业度的题 | 让读者从"看看"变成"信你" |
| 营销选题/ | 推动咨询或购买的题 | 让信任的人迈出付费第一步 |

## 每个选题文件的格式

AI 生成或你手动存入的选题，统一用这个格式：

```
标题方向：[具体的标题，不是主题]
类型：流量 / 人设 / 营销
写给谁：[具体描述这个选题针对的读者处境]
核心角度：[用一句话说你的独特判断，不是描述事实]
大概怎么写：
  开头：[用什么方式切入，3秒抓住读者]
  中间：[几个支撑点，每个用什么素材]
  结尾：[收尾方向，有没有行动引导]
来源：对标 / 定位生成 / 热点 / 自己想的
录入日期：
```

## 三种类型比例建议

一般情况下保持：流量 50% + 人设 30% + 营销 20%

如果你正在推新产品，营销型可以临时提高到 35%。
