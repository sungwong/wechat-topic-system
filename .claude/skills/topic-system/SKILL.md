# 选题生产系统

## 前置：定位检查

每次执行任何指令前，先读 `我的定位.md`。

判断定位是否可用——至少填写了：我是谁 / 帮谁 / 解决什么问题。

**定位不可用时**，不执行生成任务，先问：

> 我来帮你梳理定位，回答我3个问题：
> 1. 你现在主要在做什么？（一句话）
> 2. 你的内容主要写给什么样的人？
> 3. 他们最常遇到什么问题，你能帮他们解决？

用户回答后，整理成定位格式写入 `我的定位.md`，再继续原任务。

---

## 指令一：「定位细化」→「生成选题」连续流程

**核心思路**：别让AI直接"给选题"，先帮用户把定位切成可操作的块，再一块一块生选题。

**目标**：输入初选定位 → 拆矩阵 → 用户选交叉点 → 生选题角度 → 生具体标题，三步走。

---

### 接收初选定位

读取 `我的定位.md`。如果定位已填写，直接进入第一步。

如果定位只有笼统描述，引导用户补全为标准格式：

> 我是谁 + 帮谁 + 解决什么问题 + 用什么方式 + 核心差异
>
> 例：「AI公众号获客陪跑，帮有产品的传统行业老板解决精准流量问题，用AI提效自己做，不做代运营」

---

### 第一步：定位细化矩阵

沿三个维度各列出3-5个细分选项：

- **人群细分**：目标读者按身份/职业/背景可以分成哪几类
- **阶段细分**：他们在这件事上做到了哪一步（完全没启动 / 有号没流量 / 有流量没转化 / 想放大但没时间）
- **痛点细分**：他们最卡在哪里（不知道写什么 / 写了没人看 / 有阅读没咨询 / 咨询不成交 / 想放弃）

输出矩阵表格：

| # | 人群 | 阶段 | 痛点 | 读者画像 | 爆款潜力 |
|---|------|------|------|---------|---------|
| 1 | [人群A] | [阶段1] | [痛点X] | [一句话描述这类人现在的处境] | ⭐⭐⭐ |
| 2 | … | … | … | … | ⭐⭐ |

**爆款潜力打分标准**：人群基数大 + 痛点够刚需 + 阶段有强烈情绪 = 三星；任意一项弱则降星。

表格下方单独标注：
> 推荐优先打：[编号] — [一句话说为什么这个组合最可能出爆款]

问用户：
> 以上哪几个交叉点是你现在最想打的？报编号，我立刻进入下一步。

---

### 第二步：交叉点 → 选题角度

用户确认交叉点后，每个交叉点生成5个选题角度：

| 角度类型 | 选题方向 |
|---------|---------|
| 反常识 | [颠覆读者对这件事的惯性认知] |
| 身份共鸣 | [让目标读者觉得"这说的就是我"] |
| 结果承诺 | [用具体数字/案例承诺可达到的结果] |
| 恐惧诉求 | [放大不改变会付出的代价] |
| 方法清单 | [给出具体可执行的步骤清单] |

问用户：
> 选哪个角度？我来出具体标题。

---

### 第三步：角度 → 具体标题

用户选定角度后，用三个公式各生成1个标题，共3个候选：

```
公式A（反转型）：为什么【人群】【负面结果】？我用【方法】实现【反转】
公式B（数字型）：【数字】【人群】都有的【痛点】，【解决方案】
公式C（身份型）：【身份】做【事】，【反常识观点】
```

**每个标题附上**：
```
标题：[具体标题]
写给谁：[人群+阶段+痛点]
核心角度：[你的独特判断，一句话]
大概怎么写：开头___ / 中间___ / 结尾___
```

多个交叉点连续输出，中间用 `---` 分隔，不停顿不等待。

---

### 第四步：入库

问用户：哪几个要存入选题库？报编号即可。

用户确认后，向 `选题库/原创选题.md` 表格批量追加，来源填：定位生成。

---

## 指令二：「生成选题」（独立触发）

**触发场景**：用户直接说「生成选题」，不经过定位细化。

**执行步骤**：

1. 读取 `我的定位.md`，用整体定位作为锚点，提示先做「定位细化」会更精准
2. 生成15个选题（流量/人设/营销切入各5个），格式同上
3. 问用户哪几个入库，批量写入 `选题库/原创选题.md`，来源填：定位生成

---

## 指令三：「找对标选题」

**触发条件**：用户发来文章链接，同时说了「拆解选题」「纯选题」或类似表达时，启动本指令，用完整三层框架拆解。

**目标**：输入爆款文章链接，两层拆解——先拆标题（表面钩子），再拆选题（底层逻辑），最后用迁移公式改造成自己的选题。

### 第一步：读取文章

用 `web-access` skill 抓取全文，存入 `选题库/来源文章/[文章标题]/原文.md`。

### 第二步：完整拆解（三层）

读完全文后，按以下结构输出拆解报告：

---

**【拆标题】**

```
原标题：[原文完整标题]
钩子结构：[类型] — [一句话说清楚怎么抓眼]
吸睛关键词：[词1]（为什么有独立吸引力）、[词2]（原因）
可复用公式：[用【变量】标注可替换部分的句式骨架]
```

钩子类型：反常识 / 数字对比 / 身份标签 / 悬念 / 承诺型 / 认知升级

---

**【拆选题——第一层：打开决策】**

```
选题类型：流量型/人设型/营销型 — [在作者商业闭环里承担什么角色]

人群锚点：
  人群：[身份/职业/背景]
  阶段：[在这件事上做到了哪一步]
  痛点：[最卡在哪里]
  代入点：[作者怎么让读者觉得"这说的是我"]

冲突设计：
  表面冲突：[读者看到标题感知到的矛盾]
  深层冲突：[文章真正揭示的张力]

发布时机：[早8点/午12点/晚10点？对应什么阅读心理和场景]
```

---

**【拆选题——第二层：读完体验】**

```
开头锚定：[怎么让人继续读？戳痛点/给悬念/亮身份/抛数据，具体用了哪种]

信息密度：[大约每多少字出现一个钩子（金句/案例/转折）]

案例用法：[用的是自己的/学员的/名人的/虚构的？各起什么作用]

情绪曲线：[焦虑→希望→方法→行动，每个转折点在哪里、怎么铺]

结尾设计：[怎么收？总结/升华/引导互动/埋钩子]
```

---

**【拆选题——第三层：行动诱导】**

```
软广位置：[前1/3 / 中间 / 结尾？用了哪种植入方式]

信任铺垫：[多久开始"秀肌肉"？用数据/案例/身份哪种方式建立信任]

行动指令：[有没有明确下一步？关注/加微信/留言/点击，怎么说的]
```

---

### 第三步：迁移清单，生成仿写

读取 `我的定位.md`，提取所有定位方向，**逐条替换迁移清单，每个方向生成一个仿写标题**。

迁移清单（每个方向填一遍）：

先逐条写出原文的值，再逐条写出替换后的值。

```
**原文 =**
[ ] 标题公式：[原文用的句式骨架，用【变量】标注可替换部分]
[ ] 开头锚定方式：[原文怎么让人继续读——戳痛点/给悬念/亮身份/自曝失败/抛数据]
[ ] 核心案例类型：[自己亲历/学员案例/名人案例/虚构场景，故事弧是什么]
[ ] 情绪转折点位置：[在哪里从焦虑切到希望，用什么触发这个转折]
[ ] 转化植入方式：[在哪里、用什么方式引向下一步行动]
[ ] 整体篇幅：[原文约多少字，阅读时长约几分钟]

**逐条替换为我的定位 →**
[ ] 标题公式：[套用原文骨架，替换人群/冲突/价值关键词]
[ ] 开头锚定方式：[同样结构，换成我的人群和痛点场景]
[ ] 核心案例类型：[用自己的/学员的，故事弧对应调整]
[ ] 情绪转折点位置：[把原文触发转折的角色/事件，换成我的版本]
[ ] 转化植入方式：[引向我的产品/服务/下一步，位置保持不变]
[ ] 整体篇幅：[根据我的受众阅读习惯调整，说明理由]
```

原文选题 = 人群A + 冲突B + 价值C + 场景D
仿写 = 替换为我的：人群A' + 冲突B' + 价值C' + 场景D'

输出格式：

```
---
[方向1·赛道关键词]
迁移：人群[原→我的] / 冲突[原→我的] / 价值[原→我的]
仿写标题：[标题]

[方向2·赛道关键词]
迁移：人群[原→我的] / 冲突[原→我的] / 价值[原→我的]
仿写标题：[标题]
---
```

**仿写铁律**：
1. 吸睛关键词必须迁移：原词能用就保留，不能用就找同等吸睛力的词
2. 用读者嘴里的词，不用行业黑话
3. 数字公式必须完整自洽：大目标/单价/份数三个数字都在，乘法结果要对
4. 不是抄内容，是抄"让读者这样体验"的设计——结构/节奏/情绪曲线可以迁移，具体内容必须是自己的

每个标题≤20字，零修改可发。

### 第五步：拆解后确认

主动问用户：
> ① 冲突设计说得准吗？有没有更深的张力我没挖到？
> ② 有没有哪个词让你很有感觉，但我没提到？

等用户回应后，把补充点合并进入库版本。

用户确认后：

## 第二层：读完体验
开头锚定：...
信息密度：...
案例用法：...

## 指令四：「观点成题」

**触发方式**：用户说「观点成题」，或直接输入一段自己的想法/痛点/方向/案例。

**目标**：把用户的原材料（不管是一句话、一个观察、还是一个案例）转化成有钩子的公众号选题。和「定位细化生成选题」是两条路——那条路是AI主动批量产出，这条路是用户有了原材料，AI帮判断类型、匹配结构、打磨标题。

---

### 第一步：判断原材料类型

用户输入后，先判断是以下哪种类型，然后用对应追问锐化：

| 类型 | 判断方式 | 追问方向 |
|------|---------|---------|
| 一个痛点 | 描述的是某种困境/卡住的状态 | 这个痛点背后，读者真正恐惧的是什么？ |
| 一个观点 | 有明确判断，"我认为…""其实…" | 这个观点反常识吗？能挑战什么普遍做法？ |
| 一个方向 | 笼统的主题词，还没有锐化 | 具体哪个场景下？启动/坚持/恢复/放弃？ |
| 一个案例 | 讲了一件发生过的事 | 这个案例能提炼什么可复制的方法或认知？ |

**如果输入模糊**，不要直接跳到标题，先追问一个问题帮用户锐化：
> 你的意思是说，大多数人以为[A]，但你认为其实是[B]，对吗？

---

### 第二步：匹配选题结构

根据类型，选一种结构往里套：

| 结构 | 适用场景 | 公式 |
|------|---------|------|
| 反常识挑战 | 观点类，颠覆普遍认知 | 为什么【普遍做法】，反而【负面结果】？ |
| 恐惧诉求 | 痛点类，戳中深层焦虑 | 【人群】最大的错觉：【错误认知】 |
| 身份共鸣 | 方向类，让读者对号入座 | 【人群】的【典型困境】，本质是【深层问题】 |
| 方法承诺 | 案例类，提炼可复制路径 | 我用【具体动作】，帮【谁】实现【具体结果】 |
| 结果对比 | 有数据/前后变化 | 从【A状态】到【B状态】，我们只改了【一个点】 |

---

### 第三步：打磨标题 + 观点强度检测

**先做观点强度检测**（内部判断，不输出），再决定标题方向：

| 检测项 | 平淡 | 暴烈 |
|--------|------|------|
| 挑战对象 | 没人这么做 | 大家都在这么做，且觉得是对的 |
| 情绪代价 | 知道了更好 | 原来我一直在害孩子/浪费时间 |
| 身份威胁 | 方法不对 | 我的认知/努力/付出本身是错的 |
| 行动反转 | 多做一点 | 立刻停止/反过来做 |

**暴烈度不够时**，主动升级：

```
平淡 → 暴烈示例：
"鼓励孩子比批评孩子更好" → "你越夸孩子聪明，他越不敢挑战难的事"
"要培养内驱力" → "奖励贴纸正在吃掉孩子的内驱力"
"家长要控制情绪" → "你的情绪稳定，正在教会孩子压抑"
```

**输出三个标题候选**，每个标题过一遍检查清单：

```
[ ] 有人群标签（知识博主/咨询师/做IP的人）
[ ] 有情绪词或冲突感（错觉、真相、反而、差点、白费）
[ ] 有具体场景或结果（不是"提升转化"，是"私信没人回"）
[ ] 读完能想象内容长什么样
```

**输出格式**：

```
原始输入：[用户原话]
类型判断：[痛点/观点/方向/案例]
结构选择：[匹配的结构类型 + 一句话说为什么选这个]
强度评估：[平淡/中等/暴烈] — [一句话说暴烈在哪里，或为什么需要升级]

---
标题A（[结构名]）：[标题]
标题B（[结构名]）：[标题]
标题C（[结构名]）：[标题]
---

推荐：[A/B/C] — [一句话说为什么]
大概怎么写：开头___ / 中间___ / 结尾___
```

用户选定后，展开完整的"大概怎么写"，问是否入库。

**入库时**，向 `选题库/原创选题.md` 表格追加一行，来源填：观点成题

---

## 指令五：「热点选题」

**触发方式**：用户说「热点选题」，或粘贴一个热点事件/话题/关键词。

**核心思路**：热点是流量入口，但必须锚定定位，否则来的不是目标用户。五步走：输入热点 → 匹配判断 → 锁定角度 → 生成标题 → 输出内容框架。

---

### 第一步：接收热点信息

如果用户只发了关键词或链接，主动补问：

> - 热点来源（微博/抖音/新闻/社群）：
> - 当前传播阶段（爆发期/发酵期/长尾期）：

传播阶段影响写作节奏：爆发期追速度、发酵期追深度、长尾期追应用。

---

### 第二步：热点-定位匹配判断

读取 `我的定位.md`，从四个维度分析，内部判断后输出结论：

| 维度 | 分析内容 |
|------|---------|
| 热点的核心情绪 | 愤怒/焦虑/共鸣/好奇/娱乐？读者带着什么情绪在看这件事？ |
| 热点涉及的人群 | 与我的目标用户重叠度高/中/低？ |
| 可切入的角度 | 事件本身 / 背后现象 / 当事人选择 / 舆论反应 / 长期影响 |
| 与我定位的关联点 | 这个热点能印证/挑战/延伸我的哪个核心观点？ |

**输出判断结论**：

```
热点情绪：[核心情绪]
人群重叠：高/中/低 — [一句话说明]
最强关联点：[热点和你定位的交叉在哪里]
判断：值得跟 / 谨慎跟 / 放弃

原因：[一句话说明]
时效建议：[建议几天内写完，过了窗口期流量会大幅衰减]
```

判断为"放弃"则直接告知原因，不继续。

---

### 第三步：锁定切入角度

判断值得跟后，从五个角度选最合适的1个：

| 角度 | 适用场景 | 公式 |
|------|---------|------|
| 当事人选择分析 | 热点涉及具体人物决策 | [人物]选择[A]而非[B]，背后是[你的核心观点]的缺失 |
| 舆论盲区挖掘 | 大家都在骂/赞，你看到了另一面 | 所有人都在说[表面]，没人看到[深层]——这才是真正的问题 |
| 目标读者行动指南 | 热点引发读者焦虑，给具体方法 | 如果你也遇到[类似情境]，[你的方法论]的[具体动作] |
| 长期影响预判 | 热点是信号，指向更大趋势 | 这件事3年后看，[某个能力/认知]才是分水岭 |
| 反常识挑战 | 热点支持的观点，你有不同判断 | 为什么我不建议[读者]跟着热点去做[普遍做法] |

输出：
> 选定角度：[角度名] — [一句话说为什么选这个]

---

### 第四步：生成标题选项

基于选定角度，三个公式各生成1个标题：

```
公式A（钩子型）："[热点关键词]：所有人都在说[A]，但我想聊聊[B]"
公式B（身份型）："[目标人群]看[热点事件]，最该警惕的是[具体点]"
公式C（方法型）："从[热点人物/事件]的[选择/结果]，我总结出[你的方法论]的[具体应用]"
```

每个标题过检查清单：
```
[ ] 有人群标签
[ ] 有热点词（保留流量钩子）
[ ] 有你的独家判断（不是复述新闻）
[ ] 和定位有真实关联，不是强行蹭
```

---

### 第五步：内容框架输出

用户选定标题后，输出完整内容框架：

```
开头锚定：[用热点场景勾住，3句话内转到读者视角，不做新闻复述]
核心观点：[你的方法论/定位如何解释或应对这个热点]
案例/方法：[具体场景的应用，或反例警示]
结尾行动：[读者今天可以做的一个具体动作]
```

问用户是否入库。入库时向 `选题库/原创选题.md` 追加一行，来源填：热点选题。

---

## 指令六：「存选题」

**触发条件**：用户说「存选题」，或在生成/拆解流程结束后说「入库」「存进去」「保存」。

**执行步骤**：

1. 判断来源：
   - 来自拆解（找对标选题）→ 追加到 `选题库/拆解选题.md`
   - 来自生成/观点/热点 → 追加到 `选题库/原创选题.md`

2. 按对应表格格式追加，不新建文件，不改动已有行

3. 确认追加成功，报告存入的条数和位置

---

## 选题质量自查

每次生成后，输出前自问：
1. 定位匹配？读者看到会觉得"这个号写这个很正常"吗
2. 有独家角度？换同赛道的人能写出这篇吗（能 → 不够好）
3. 读者会点？标题对目标读者有钩子，不是自嗨
4. 能落地写？有具体角度，不是空泛主题
5. 和业务有关联？至少间接指向用户的专业方向

五条都通过才输出。
